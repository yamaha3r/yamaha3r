### Обо мне

Кодю где-то 2–3 года. В основном это Java, Python и JavaScript.  
Сильнее всего залипаю на Minecraft — сети, пакеты, как клиент с сервером общается, боты и всякое такое.  
Параллельно пилю разную автоматизацию, ботов для тг/дискорда, пробую нейросети и потихоньку лезу в реверс.

Учусь на всём подряд, что интересно.
